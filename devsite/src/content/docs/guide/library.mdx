## When the server doesn't answer

Ephyra notices when your server stops answering: on a network change, when you return to the
app and after a failed request. On the phone and tablet a banner then says so, with a way to
your [downloads](/ephyra/guide/downloads/#without-the-server), and it goes by itself when the
server is back. Screens that fail to load say so and offer Retry.
