## Choosing a quality

Each download asks for a quality. **Original** copies the file as it is on the server: the best
picture, the largest file, and no work for the server. Every other choice is a copy the server
converts while you download, from 4K down to 360p: smaller, and it plays on a device that can't
play the original. Your account on the server needs permission to download.

## Without the server

There is no offline mode to switch on. On a plane or when the server is down, open the app as
usual: a banner says the server doesn't answer and leads to Downloads, and Favorites, Media and
search show what is downloaded. What you watch is kept and sent to the server when it is back,
so Continue Watching is right on your other devices too.

## Where they are stored

Settings → Downloads sets the storage (internal or an SD card) and how many downloads run at
the same time. Downloads resume by themselves after a lost connection or a restart.
