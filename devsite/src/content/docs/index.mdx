How [Ephyra](https://midasvo.nl/ephyra/) is built, for people and for agents. Ephyra is an
Android Jellyfin client for phones, tablets and Android TV, a fork of
[Findroid](https://github.com/jarnedemeulemeester/findroid).

Every page here is a Markdown file of the [repository](https://github.com/midasvo/ephyra),
copied at build time: what you read on GitHub, what an agent reads in a checkout and what this
site shows are the same text. Each page links to its source at the bottom. The status of this
site: a first version (issue [#928](https://github.com/midasvo/ephyra/issues/928)); three of
the fifteen areas have a guide.

## For agents

- The raw Markdown of every page is linked at its bottom; [llms.txt](/ephyra/dev/llms.txt)
  lists them all.
- In a checkout, `CLAUDE.md` is the entry point, `docs/areas.yaml` the map and
  `.claude/skills/start-work` the skill that turns "I want to work on subtitles" into the
  guide, the files, the rules, the checks and a brief.

## How this site is built

The source is `devsite/` (Astro Starlight). `devsite/scripts/sync-docs.mjs` lists the Markdown
files that become pages. The architecture model is LikeC4 in `docs/architecture/model/`; its
module part is generated from the build files by `GeneratedDocsTest` in `architecture/`, which
fails when it is out of date. `.github/workflows/pages.yml` builds this site next to the Ephyra
site.
